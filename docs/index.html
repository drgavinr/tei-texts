This Github Pages site contains human-readable HTML versions of Text Encoding Initiative editions of Public Domain texts. For source code and documentation, see the tei-texts repository. The following texts are currently available:

  • sandall/: Thomas Edward Sandall, A History of the 5th Battalion the Lincolnshire Regiment (1922). Official history of an infantry battalion of the British Army in the First World War.
  • Letters of Nehemiah Wharton, a soldier in the English Civil War. Available with three sets of transcription conventions:
    • diplomatic: preserves original orthography as far as possible and does not expand abbreviations.
    • clean: a more readable version of the text with silent expansions and regularizations.
    • intermediate: part way between the two, with silent regularization of some archaic letter forms, and expansions in square brackets.
